## 🤝 Code of Conduct

Be kind, be respectful, assume good intent.
Harassment, discrimination, or toxic behavior of any kind will not be tolerated.
By participating, you agree to uphold a welcoming, inclusive environment for everyone.

---

## 💡 Ways to Contribute

- 🐛 **Report bugs** — open an issue with a clear reproduction.
- ✨ **Suggest features** — describe the use case, not just the solution.
- 📝 **Improve docs** — typos, unclear sections, missing examples.
- 🧪 **Write tests** — coverage is always welcome.
- 🔌 **Add adapters** — Azure Blob, MinIO, DigitalOcean Spaces, etc.
- 🌍 **Translate** — help make the README accessible to more people.
